# 狐狸基金 · ShowMeFox

一个集中展示个人基金持仓的 Android App：把分散在支付宝、天天基金、银行 App 等不同平台的基金，
汇总到一个总面板里，每天看一次就知道总资产、今日盈亏和累计盈亏。

## 安装到小米手机

APK 在 `dist/狐狸基金-v1.0.0.apk`（约 5.3 MB，已签名）。

**方式一：数据线安装（推荐）**

1. 小米手机打开「设置 → 我的设备 → 全部参数 → 连点 MIUI 版本 7 次」开启开发者选项
2. 「设置 → 更多设置 → 开发者选项」里打开 **USB 调试**
3. 手机连电脑，手机上弹出的授权框点「允许」
4. 运行：
   ```bash
   adb install -r "dist/狐狸基金-v1.0.0.apk"
   ```

**方式二：直接传文件**

把 APK 拷到手机（微信文件传输 / QQ / U 盘均可），用文件管理器点开安装。
小米会提示「未知来源应用」，需要在弹出的设置里允许对应应用安装未知应用。

> 注意：这是自签名 APK，不是应用商店版本。小米的「纯净模式」可能会拦截，
> 如果装不上，去「设置 → 应用设置 → 纯净模式」里关闭，或在安装拦截弹窗里选「仍要安装」。

**卸载**：长按图标 → 卸载。数据会一起删掉。

## 怎么用

1. 打开 App，点右下角「＋ 添加基金」
2. 先选平台（比如「支付宝」）；第一次用会提示你先建平台
3. 输入 6 位基金代码，或直接输名字搜索（如「易方达」）
   - 输入代码后会自动回显基金全名，用来确认没输错
4. 填**持有份额**和**买入成本**，保存
5. 回到主界面，自动拉最新净值并算好市值、今日盈亏、累计盈亏

**主界面读法**

- 顶部大卡片：全部平台加起来的总资产 / 今日盈亏 / 累计盈亏 / 总成本
- 下面的平台卡片：每个平台的小计（当日盈亏按当日涨跌着色，累计收益率在副标题）
- 卡片内每行：一只基金 —— 名称、代码、净值、净值日期、市值、涨跌幅和当日盈亏

**手势**

- 点击基金行 → 修改份额 / 成本，或删除
- 点击平台标题 → 重命名 / 删除平台
- 下拉 → 刷新全部净值
- 右上角 ⟳ → 手动刷新

## 数据来源与准确性

- 净值 / 涨跌幅来自东方财富公开接口（`fundmobapi.eastmoney.com`），失败时自动降级到
  单只接口 `api.fund.eastmoney.com/f10/lsjz`，再失败走腾讯行情兜底，最后用本地缓存。
- **没有「盘中实时估值」**：该接口（`fundgz.1234567.com.cn`）目前整站不可用，
  详见 `docs/fund-api.md` 的实测证据。所以界面只显示**已确认的最新净值 + 净值日期**，
  不会拿一个假的估算值糊弄你。
- 涨红跌绿，符合国内习惯；货币基金没有涨跌幅概念，显示「—」。
- 断网时保留上次成功的数据，并在顶部提示，不会把金额清成 0。

**计算口径**

```
持仓金额 = 持有份额 × 最新单位净值
当日盈亏 = 持仓金额 × 当日涨跌幅
累计盈亏 = 持仓金额 − 买入成本
```

## 开发

```bash
# 编译（需 JDK 17 + Android SDK 34）
gradle assembleDebug

# 跑单元测试（含真实接口样本解析、金额计算、界面渲染）
gradle testDebugUnitTest

# 跑真实网络集成测试（会真的请求东方财富）
gradle testDebugUnitTest -DnetTest=true

# 打正式签名包
gradle assembleRelease
```

- 签名证书：`release.keystore`，别名 `showmefox`
- 界面截图：`docs/screenshots/`
- 接口实测报告：`docs/fund-api.md`

## 已知限制

- 数据存在本机（`filesDir/fund_data.json`），不联网同步，换手机需要重新录入
- 不支持导入平台账单，份额和成本需要手动填
- 净值一般交易日 19:00–23:00 更新，白天看到的是上一个交易日的净值
- QDII / 海外基金净值滞后 1–2 天，看「净值日期」为准
